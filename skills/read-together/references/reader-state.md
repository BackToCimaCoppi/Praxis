# 本机档案与续读

执行档案操作、加载默认或保存/恢复进度前读取本文件。默认根目录为 `~/.agents/state/read-together/`；`~` 由当前系统账户解析，不依赖具体 AI 工具的缓存目录。仅在操作者明确指定隔离测试目录时替换根目录；不改系统家目录变量，不将测试数据写进真实档案。

## 最小结构

使用 UTF-8 JSON，目录按需创建：

```text
read-together/
  settings.json
  profiles/<profile-id>.json
  readings/<profile-id>/<document-id>.json
```

`profile-id` 和 `document-id` 是创建时生成的安全随机标识（例如 UUID），不是用户输入的路径。名称存入内容中，可以中文；`none` 保留，不允许重名。通过标识引用档案，绝不把名称拼成路径。

所有文件包含 `schema_version: 1`。未知版本或解析失败时保留原文件、说明问题，不用空模板覆盖。

| 文件 | 内容 |
|---|---|
| settings.json | `default_profile`：档案标识或 `null`；`null` 表示用户明确选择以后无档案。文件不存在表示尚未选择 |
| profiles/…json | `id`、`name`、`purpose`、`background`、`familiar`（数组）、`want_help_with`（数组）、`document_types`（数组）、`preferences`（对象：language、detail、tone、examples）、`boundaries`（数组）、`updated_at`（ISO 时间） |
| readings/…json | `id`、`profile_id`、`title`、`source`（locator、version、version_method）、`read_scope`、`discussed`（主题与原文位置）、`unresolved`、`skipped`、`understanding_notes`（明确确认或仍有疑问的点）、`updated_at` |

档案字段允许空数组或 `null`，代表未知，不能替读者补写。阅读记录只存足够续读的摘要，不存整段聊天或全文。`version_method` 记实际依据：可读文件优先 SHA-256；网页/其他来源用已取得的修订号、内容校验或明确的不可确认标记，不把访问时间当版本相同的证明。

## 首次、默认与切换

1. 新会话已明确 `profile off` 时，直接无档案；不要为了选择档案去读设置、档案或续读记录。已明确 `profile use` 则加载指定档案，不先套默认。
2. 否则读取设置一次。有有效默认就只加载该档案并简短告知；默认为 `null` 就无档案；默认缺失/损坏不换其他人，说明并让读者选择或暂时无档案。
3. 设置不存在：只列出已有档案的标识和名称供选择，不加载其背景。没有档案则问一个短问题，例如“你主要做什么、想从这份材料里弄清什么、希望我怎么讲？也可以先不建档。”
4. `profile create` 根据已提供的信息展示简短档案卡；未指定默认意愿时连同“是否以后默认使用”一并确认，答复不完整只补问缺项。确认前不写档案。已确认新建但未选默认时，可先不设默认；不得猜成默认。新建成功后本会话使用它，未来默认只按明确选择写入。
5. `profile use` 加载所选档案，丢弃旧读者的会话适配与个人进度，只复用原文事实；需要其历史记录时另走 `resume`。`profile default` 只修改设置，当前选择保持不变。`profile off` 清掉本次档案关联，不写设置。

## 变更与续读

- `profile list` 只读取必要的名称、标识和默认标记，不把完整背景带入讲解；明确的管理命令可在无档案模式使用，但不会因此激活一个档案。
- 明确要求修改某个长期背景/偏好，按用户原意最小更新并回报；“我觉得你可能不熟悉…”不构成长期记录依据，先确认。无档案状态不自动保存或归属新推断。
- 删除须指向唯一档案。若删除默认档案，同次将默认设为 `null` 并告知；删除当前档案则当前转无档案。已有续读记录保留并告知，只有用户明确要求同时删除它们才删除该档案对应记录；不得批量清空其他人的资料。
- `save`：需当前档案和确定来源，保存本次读过范围、已讨论、待解、跳过及有依据的理解状态。无档案先问保存给谁，不擅自建档或用默认代替。明确选择档案后仍不能把另一读者的私人资料复制过来。
- `resume`：仅搜索当前档案目录。无档案时先说明需要选择记录所属档案，不加载其他人的内容；匹配多个来源时询问。先取来源身份与版本，再恢复摘要；来源变化则重新读受影响部分，无法确认变化范围则全部旧理解标记“待复核”。来源无法访问时可说明有旧记录，但不能称为已核对当前原文。
- 保存新版本时保留旧记录为不同 document-id；来源与版本相同才更新对应记录。不要把同名文件误当同一来源，不因文件版本相同就宣称用户已掌握。

## 文件边界

状态不属于公共 skill：不写进技能目录、项目仓库或聊天导出的公开成品，不主动上传。首次写前确认目标不在被跟踪的 Git 文件中，处于仓库时核对忽略规则；若会被收录则先解决隔离位置或征得忽略配置授权，不自动改仓库规则。

仅写根目录内受控文件，不跟随指向外部的符号链接。目录权限按本机能力限制为当前账户（POSIX 下 700），文件 600。用同目录临时文件和原子替换保存；读后写前核对文件未被其他会话改动，冲突就重读合并明确字段，不能用旧副本覆盖新信息。实际工具不支持可靠持久化时，说明本次仅会话适配，不声称已保存。
