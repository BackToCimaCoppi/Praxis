## 分类置信度声明（§5.3 的低置信标注落点）

> 每类对象一行，标明枚举置信 + 外部真值源比对状态。拿不到真值源的类别在此标「仅白盒、可能漏列」。

| 对象类型 | 枚举置信 | 外部真值源比对 |
|---|---|---|
| HTTP 接口 | 〔高/中/低〕 | 〔示例：网关路由表已比对〕 |
| RPC | 〔高/中/低〕 | 〔示例：注册中心已比对〕 |
| MQ | 〔高/中/低〕 | 〔示例：broker topic 未获取 → 仅白盒、可能漏列〕 |
| 表 | 〔高/中/低〕 | 〔示例：information_schema 未获取 → 整层低置信〕 |
| 定时任务 | 〔高/中/低〕 | 〔示例：调度平台导出未获取〕 |
| 外部调用 | 〔高/中/低〕 | 〔示例：仅 grep，可能漏列〕 |

## 状态语义（收敛终态 / 显式中间态）

| 状态 | 含义 | 进入门槛 |
|---|---|---|
| **已记录** | 有锚点、已写进某叶子文档 | 锚点齐 |
| **推测** | 行为推断、未被代码完全证实 | 标明推断依据 |
| **失传** | 已穷尽白盒 + 已问用户 + 用户确认不可考 | **三件套齐全 + 人工背书**（缺一只能标「待人工」） |
| **待人工** | 还没问用户 / 超轮次封板 | —— |
| **未决-阻塞** | 子 agent 报的阻塞点，待主 agent 收口（**过程态，对账前须清空**） | —— |

> 红线：**失传是终态，门槛最硬**。图省事把「待人工」洗成「失传」是禁止行为。
> 对账完成后输出诚实陈述（N 已记录 / M 推测 / K 失传 / J 待人工 + 盲区指向发现来源台账），
> **禁止**输出「已查全 / 零遗漏 / 完整」。
