# 形态标定样例

> **这是形状标定用例，不是骨架模板。** 别照抄下面三段的整体结构去套自己的文档——要学的是同一套 token 机制（`:root` 定义语义色 → `prefers-color-scheme` 跟随系统 → `data-theme` 手动覆盖）怎么随"主信息载体"变形成不同的视觉语言。三个例子刻意只覆盖设计文档/技术文档/业务QA这三种最常见的形状，没有第四个（比如时间线/复盘）——遇到时按 SKILL.md 第1节的判断逻辑现推，不强行往这三个里套。

三段共用的 token 声明方式（每段片段里都重复了一份，实际写文档时只需要一份，按当次需要的语义轴命名）：

```css
:root{
  --bg:#f7f8fb; --surface:#fff; --ink:#1b2333; --ink-soft:#5b6579;
  --status-done:#1a7f5a; --status-doing:#b4780a; --status-blocked:#c23b3b;
  --cat-a:#3a5aa8; --cat-b:#8a4ec2; --on-status:#fff;
}
@media (prefers-color-scheme: dark){
  :root{ --bg:#14171f; --surface:#1d212c; --ink:#e6e9f0; --ink-soft:#9aa3b5;
    --status-done:#3fd694; --status-doing:#e0a83a; --status-blocked:#f0685f;
    --cat-a:#7fa1e8; --cat-b:#c99ce8; --on-status:#14171f; }
}
:root[data-theme="dark"]{ /* 同上一层深色变量，供手动切换按钮覆盖系统偏好 */ }
:root[data-theme="light"]{ /* 同最上层浅色变量 */ }
```

注意 `--on-status`：徽章背景=状态色时，叠在上面的文字颜色不能写死 `#fff`，因为深色模式下状态色会变亮变饱和，白字对比度会不合格（详见 `色彩与主题参考.md` 的实测数据）。下面两个片段的 `.verdict`/`.tag` 都用 `color:var(--on-status)`，不是硬编码白色。

---

## 1. 决策记录表片段（设计文档场景）

用表格摆"选了什么 / 放弃了什么 / 为什么"，每个决策点锁死到唯一选择——不用大段文字论证，用表格把取舍钉死。

```html
<style>
  .decision{background:var(--surface);border-radius:10px;padding:18px 20px;margin:14px 0}
  .decision table{width:100%;border-collapse:collapse;font-size:14px}
  .decision th{text-align:left;color:var(--ink-soft);font-weight:600;padding:6px 10px;border-bottom:1px solid var(--ink-soft)}
  .decision td{padding:8px 10px;vertical-align:top;color:var(--ink)}
  .verdict{display:inline-block;padding:2px 10px;border-radius:20px;font-size:12px;font-weight:700;color:var(--on-status)}
  .verdict.chosen{background:var(--status-done)}
  .verdict.dropped{background:var(--status-blocked)}
</style>
<div class="decision">
  <table>
    <tr><th>方案</th><th>结论</th><th>为什么</th></tr>
    <tr><td>方案A：xxx</td><td><span class="verdict chosen">采用</span></td><td>一句话理由</td></tr>
    <tr><td>方案B：xxx</td><td><span class="verdict dropped">放弃</span></td><td>一句话理由</td></tr>
  </table>
</div>
```

## 2. 代码块 + 目录导航片段（技术文档场景）

篇幅长、需要跳转时才加 sticky 目录；代码块自己横向滚，不拖累整页。

```html
<style>
  .layout{display:flex;gap:28px;align-items:flex-start}
  nav.toc{position:sticky;top:16px;flex:0 0 180px;font-size:13px}
  nav.toc a{display:block;padding:4px 0;color:var(--ink-soft);text-decoration:none}
  nav.toc a:hover{color:var(--cat-a)}
  main{flex:1;min-width:0}
  pre{background:var(--surface);border-radius:8px;padding:14px 16px;overflow-x:auto;
    font-size:13px;line-height:1.6;color:var(--ink)}
</style>
<div class="layout">
  <nav class="toc"><a href="#a">一、背景</a><a href="#b">二、实现</a><a href="#c">三、验证</a></nav>
  <main>
    <h2 id="b">二、实现</h2>
    <pre><code>function example() {
  return "宽代码块只在自己范围内滚动";
}</code></pre>
  </main>
</div>
```

## 3. 问答卡片片段（业务QA场景）

一问一答，用状态标签标记"已解决/待定/风险"这类结论轴，不用状态色表示别的含义。

```html
<style>
  .qa{background:var(--surface);border-radius:10px;padding:14px 18px;margin:10px 0}
  .qa .q{font-weight:700;color:var(--ink);display:flex;gap:8px;align-items:center}
  .qa .tag{font-size:11.5px;font-weight:700;padding:1px 9px;border-radius:20px;color:var(--on-status)}
  .tag.done{background:var(--status-done)} .tag.doing{background:var(--status-doing)} .tag.blocked{background:var(--status-blocked)}
  .qa .a{margin-top:8px;color:var(--ink-soft);font-size:13.5px;line-height:1.65}
</style>
<div class="qa">
  <div class="q">Q：xxx问题？ <span class="tag blocked">风险</span></div>
  <div class="a">A：具体回答内容。</div>
</div>
```
