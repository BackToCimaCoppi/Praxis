## 12. 更新规则

详见 `~/.claude/skills/control/references/总控规范.md` §2。简要：

- 子任务开始时改 `进行中`，开始前必须**重读**该子任务的强制阅读文件
- 完成后改 `已完成`，**立刻停止**，不顺手做下一个
- 阻塞时改 `阻塞` 并写明原因
- 产出文件回填「输出物」
- 整体完成 → 用 `archive_control.py --apply` 自动归档
- 任务删除 → 见总控规范 §2.4，**不进归档**

## 13. 过程资产放置规则

> 总控规范 §1.1.1 的本任务内化版本，子任务作者必读。

- 所有过程资产 → 唯一目录 `_shared/`，归属由文件名前缀区分：
  - 子任务专属 → `_shared/T{n}-{资产名}`（多文件用 `_shared/T{n}-{资产名}/` 子目录）
  - 任务级共享（无单一归属） → `_shared/{资产名}`（无前缀）
- 高频资产标准名：`T{n}-轻量设计方案.md` / `T{n}-goal章程.md` / `T{n}-goal飞行日志.md` / `T{n}-对抗评审报告.md` / `自愈清单.md`（任务级无前缀）
- 进入项目正式文档体系的产出 → 项目本地约定路径，不放在本任务目录
- **禁止**：资产平铺到任务根目录、新建 `_T{n}/` 目录（旧规则已废除）
- 所有资产路径登记在对应子任务详情的「输出物」字段，本节不重复列清单
