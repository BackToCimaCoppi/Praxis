- **状态**：待完成

## 子任务背景

交付 / 发布验证阶段：把施工产物按项目方式交付（部署服务 / 上架 / 打包 / 验收），并跑自动化测试（含视觉验收交 VLM）。这是流水线终点的质量闸。

## 强制阅读（精准 1-3 个）

- `{{交付 skill}}`：交付/发布/部署 + 测试执行 skill —— 读完获得交付流程与测试执行方式
- 上游 `_shared/T<测试用例设计>-测试用例.md` + 施工产出的测试执行脚本

## 输入

- 施工产物（代码 + 测试执行脚本）、测试用例规格

## 要做的事情

1. 按 `{{交付 skill}}` 交付 / 发布
2. 跑能自动化的全部自动化测试（接口 / 端到端 / 视觉验收）
3. 记录交付结果与测试结果（含失败项与处理）

## 不做什么

- 不改产品代码（发现 bug → 回到对应施工子任务或另开排障，不就地改）
- 不补设计 / 不改文档真值

## 预期效果

交付物按项目方式上线/发布，自动化测试通过（或失败项明确记录并定位）。

## 输出物

- `_shared/T{n}-交付记录.md`：交付步骤 + 测试结果（VLM 视觉验收截图/结论）

## 完成判定

- [ ] 交付 / 发布完成

- 测试失败先定位归因，不就地盲改产品代码
- 交付动作不可逆面（线上发布）按项目规则先确认
