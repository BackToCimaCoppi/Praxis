1. 按 `{{测试设计 skill}}` 从全部 `SD-x` 推导测试矩阵（单元 / 接口 / DB / Web UI / 小程序 UI / 视觉 / 手工例外）

3. **（评审塌缩时）** 同一对象/基线只跑一次开放式评审；测试层不得补造业务语义。需要新业务结果时先形成 `DEC-x`，再回补用例；桶2 追加到 `_shared/自愈清单.md`
