## 12. 过程资产放置规则

> 总控规范 §1.1.1 的本任务内化版本，子任务作者必读。

- 所有过程资产 → 唯一目录 `_shared/`，归属由文件名前缀区分：
  - 子任务专属 → `_shared/T{n}-{资产名}`（二级 `_shared/T{n}.{m}-{资产名}`；多文件用 `_shared/T{n}-{资产名}/` 子目录）
  - 任务级共享 → `_shared/{资产名}`（无前缀）
- 高频资产标准名（照 §1.1.1）：`T{n}-轻量设计方案.md` / `T{n}-goal章程.md` / `T{n}-goal启动检查.md` / `T{n}-goal飞行日志.md` / `T{n}-对抗评审报告.md` / `自愈清单.md`（任务级无前缀）
- 测试用例/调查报告/探讨纪要等非标准名，作普通专属资产命名（如 `_shared/T{n}-测试用例.md`）
- **禁止**：资产平铺到任务根目录、新建 `_T{n}/` 目录
- 所有资产路径登记在对应 `Tn-{子任务名}.md` 的「输出物」字段，本文件不重复列清单
