## 12. 过程资产放置规则

> 总控规范 §1.1.1 的本任务内化版本，子任务作者必读。

- 所有过程资产 → 唯一目录 `_shared/`，归属由文件名前缀区分：
  - 子任务专属 → `_shared/T{n}-{资产名}`（二级子任务 `_shared/T{n}.{m}-{资产名}`；多文件用 `_shared/T{n}-{资产名}/` 子目录）
  - 任务级共享（无单一归属） → `_shared/{资产名}`（无前缀）
- 高频资产标准名：`T{n}-轻量设计方案.md` / `T{n}-施工蓝图.md` / `T{n}-蓝图评审报告.md` / `T{n}-对抗评审报告.md`
- 进入项目正式文档体系的产出 → 项目本地约定路径，不放在本任务目录
- **禁止**：资产平铺到任务根目录、新建 `_T{n}/` 目录（旧规则已废除）
- 所有资产路径登记在对应 `Tn-{子任务名}.md` 的「输出物」字段，本文件不重复列清单
