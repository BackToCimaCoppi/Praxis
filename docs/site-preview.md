# site-preview

> 为 HTML、Markdown 和设计预览生成手机可读的审阅目录，并在具备私有托管配置及发布授权时更新稳定直链。

## 这是什么

`site-preview` 维护本地审阅目录。原件仍是内容真值，目录和可选站点只用于审阅。支持新增或更新、查询、移除单项、按明确要求清空全部。

## 解决什么问题

本地材料在手机上难打开，频繁更新又会让审阅链接失效。直接上传整个项目还可能带上凭据、日志或内部文件。

## 为什么这么设计

先在隔离目录只装实际需要的 HTML 与资源，逐项检查依赖。项目、任务、材料各有稳定 slug；更新原 slug 即保留直链。托管能力和发布授权由使用者环境提供，通用 skill 不写死站点、账号或访问策略；缺托管时仍可交付本地目录。

## 怎么用

说“手机预览”“放到审阅站”或“清空预览”。准备输入材料后，用 `skills/site-preview/scripts/site_preview.py --help` 查询 `init`、`upsert`、`list`、`remove`、`clear`、`lock` 参数；本地浏览器以手机视口验收。已配置私有托管且获授权时发布并核验直链与访问范围，否则明确说明未发布。`remove` 仅删指定展示项；`clear` 仅在明确要求全部清空时执行。
