# read-together

> 长文共读：先弄清主线，再通过聊天逐步读懂原文。

## 这是什么

`read-together` 是一份教 AI 如何陪你读长文的 skill。
它适用于设计方案、规格文档、论文和其他长篇材料。

AI 先消化可读取的原文，再围绕你的问题讲解，核对你的理解，提醒遗漏的重要条件。
你不必一段段读它搬来的原文，也不必先学一套文档管理流程。

它不修改原文，不自动执行文档中的操作，也不保证任意长文绝无遗漏。

## 解决什么问题

长文经常把已知背景、陌生概念和关键限制放在一起。
只看摘要可能漏掉条件，逐字读又很费力。

AI 也不知道你已经懂什么。要求它“简短”，可能只剩术语；要求它“详细”，又可能讲太多。
共读把一次性写完整篇，变成按你的实际理解逐步展开。

## 为什么这么设计

- 先给主线和几个关键问题，让你知道可以从哪里问起。
- 你选哪部分，就围绕它串起相关章节，只补必要背景。
- 你用自己的话复述，AI 对照原文纠正具体误解；说对了就直接确认。
- 结束前检查尚未讨论的重要内容，减少“我不知道还有什么该问”的盲区。

这几个动作各解决一层困难：导览帮助你知道该问什么，追问让 AI 调整讲解深度，复述暴露具体误解，收尾核对补上你尚不知道该问的条件。原文始终是核对依据。

读者档案也叫“角色卡”，是一份给 AI 看的阅读说明，记录你的背景、阅读目的和聊天偏好，提供下次阅读的起点。
它可以有多个，也可以完全不用；档案不会因一次提问就把你永久标成“不懂”。

默认状态放在本机 `~/.agents/state/read-together/`，与公共技能分开。
多个档案是偏好区分，不是同一系统账户中的隐私隔离。

## 怎么用

从仓库下载后，把完整的 `skills/read-together/` 目录放到 `~/.agents/skills/`。
它独立使用，不需要安装其他 Praxis skill。
使用能加载该目录、读取材料并操作本机文件的 Agent 工具；工具未发现技能时，先按其说明重新加载或新建会话。

在聊天中开始：

```text
$read-together read <文档路径、附件或链接>
```

第一次可以介绍背景和讲解偏好，确认档案卡后保存；也可以说“先不建档”。
之后既能用命令，也能直接聊天：

```text
overview
explain 订单关闭后才收到付款通知怎么办
check 我的理解是：订单不会重新打开，而是进入退款流程
还有哪些关键条件没聊到？
```

角色管理示例：

```text
profile create 工作阅读
profile default 工作阅读
profile use 学习阅读
profile off
```

创建档案先确认内容；`profile use` 只影响本次，`profile default` 只影响未来新会话。
`profile off` 仅停用本次档案，`profile default none` 才是以后默认不用。

角色卡记录你希望怎么读；续读记录另行保存这篇材料读到哪里。
想下次继续时说 `save`；下次选择同一档案后说 `resume <文档>`。
没有档案时不会擅自保存到某个人名下。原文版本变了，旧理解要重新核对。
