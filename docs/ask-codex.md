# ask-codex

> 把一个问题或一段任务交给外部模型（通过一次性非交互命令），拿回第二意见或直接拿回改动——**分工权和最终决策权始终留在主线程**。

## 这是什么

一个轻量入口：通过一次性命令行调用外部模型（codex / GPT），让它回答问题、做审查，或者直接执行一段任务。综合与决策全部留在主线程。

它有两个模式：

- **问模式**：只读沙箱，模型物理上改不了任何东西，输出结论到文件，主线程消化后回答用户。
- **派模式**：任务和护栏一次性打包交给它执行，执行完由主线程做事后 diff 验收。

- **管**：随问随答的第二意见、非代码问题咨询、没有冻结真值可核对的场景、直接派一段任务。
- **不管**：核验代码是否照已冻结规格施工（→ `codex-review`）、开工前的方案与高风险代码评审（→ `adversarial-review`）。

## 解决什么问题

同一个外部模型在这套体系里有三个入口，它们的前提和保护机制完全不同，**混用会架空纪律**：

| 入口 | 时机 | 前提 | 输出 |
|---|---|---|---|
| `adversarial-review` | 开工前，方案待定 | 无固定前提 | 双评审 + 裁判报告 |
| `codex-review` | 施工完成后 | 必须有冻结规格与决策表 | 三级分类 + 证据闸 + 分流台账 |
| **本 skill** | 任意时刻 | 无前提，随问随答 | 自由文本结论 / 直接执行 |

最危险的误用是拿本 skill 去做代码符合性核验：`codex-review` 的证据闸和三级分流协议专门用来防"把已拍板决策误判成 bug、又被照改"，本 skill **没有这套保护**。绕开它，那套纪律就等于不存在。

另一个常被忽略的坑：一次性非交互命令**不是可持续对话的子代理**。用 `Agent` 工具起的子代理能"先探索、汇报计划、等确认再动手"；一次性命令跑完即结束，**没有"跑到一半停下来等确认"这回事**。照着子代理的两阶段模式去派任务，只会得到一个没人确认过就已经改完的工作区。

## 为什么这么设计

- **不做自动路由**：用户不说触发词，主线程自己处理；用户说了触发词，就严格按对应模式执行。分工权是人的，不是模型自己判断"这个问题我该不该外包"。
- **进入前强制边界检查**：先问一句"这是不是在核验代码是否照冻结规格施工"。命中就停下改用 `codex-review`。把这道检查写成硬前置，而不是提醒。
- **派模式是一次性直接执行**：因为工具形态就决定了没有中途确认。所以护栏必须**一次性打包进去**，验收放到事后 diff——这是对工具真实行为的诚实适配，不是偷懒。
- **问模式用只读沙箱**：不是靠提示词说"请不要改文件"，而是物理上写不了。能力边界永远比指令边界可靠。
- **约束条件必须内嵌原文**：外部模型读不到你的项目规范文档，写"参考某文档"等于没写。
- **信息来源声明是必填槽位**：已读文件白名单 + 未纳入本包的已知信息及排除原因。这让主线程能判断结论建立在什么基础上，而不是照单全收。
- **信息不足时要求它拒答**：明确要求"不要硬答，先声明缺失的关键信息，再给基于明确假设的条件性结论"。

## 怎么用

**触发词**：问一下 codex / 问一下 gpt（问模式）；让 codex 去做某事 / 让它直接改（派模式）。触发词模糊时直接问用户是哪种模式，不猜。

**进入前必查**：问题是不是"核验代码是否照已冻结规格施工"？是 → 停止，改用 `codex-review`。

**问模式打包槽位**：

```
[具体问题] — 一句话，可被独立回答，不依赖隐含上下文
[文件引用] — 精确到方法/行范围，附禁入声明"只读列出的文件，不要自行查找其他文件"
[背景事实] — 回答必需的关键事实（先浓缩，不贴大段原始代码）
[约束条件] — 从项目规范里摘出适用条款，内嵌原文
[判断标准] — 什么算好答案
```

填槽原则：先浓缩再装包、每项都过"这一条读者真的需要吗"的检验、不确定就不装、不设数字上限。

**成本提示**：默认最高推理档质量最好也最慢，调用要走后台；日常快速过一遍可以降档。

**常见坑**：

- **拿它替代 `codex-review`**：最严重的误用，直接架空证据闸与分流纪律。
- **按子代理的两阶段模式派任务**：一次性命令不会停下来等你确认，护栏必须打包在前。
- **约束写成"参考某文档"**：外部模型看不到，等于没约束。
- **派模式后不做事后验收**：没有中途确认，事后 diff 就是唯一的验收点，跳过等于没有验收。
- **让它在信息不足时硬答**：必须显式要求它先声明缺失信息，否则会拿到一个自信的错误结论。
